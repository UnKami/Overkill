# Download and play Overkill

[Download the Windows installer](https://github.com/UnKami/Overkill/releases/download/v0.23.0-test/OverkillSetup-0.23.0.exe)

[Download the portable game folder (ZIP)](https://github.com/UnKami/Overkill/releases/download/v0.23.0-test/Overkill-0.23.0-Windows.zip)

[Release notes and checksums](https://github.com/UnKami/Overkill/releases/tag/v0.23.0-test)

Run the installer, or extract the entire ZIP and launch Overkill.exe. Start a **new run** to test the 12-relic starter deck, nine-hour clock. Windows x64; no Godot installation needed. This is a playtest release with boss balance still under review.


For the 3D preview, use **Play Boneghoul preview** in the Start menu or **Play Boneghoul.cmd** in the extracted folder. [Preview notes](../docs/encounter-023.md).
