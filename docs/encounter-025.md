# Overkill 0.25.0 — Unified crystalline visual direction

Partner navigation after publication: **UnKami/Overkill → Releases → 0.25.0 → Assets → OverkillSetup-0.25.0.exe**. Install and launch **Overkill**; the campaign now uses one illustrated combat presentation for regular encounters, elites, and bosses.

## Changes since 0.24

- Established one visual canon for the playable Executioner, enemies, battlefields, relics, event imagery, transitions, menus, and combat interface: premium cinematic 3D-rendered techno-fantasy with dark gunmetal, luminous cyan and amber crystal, fractured energy, and restrained hexagonal engineering.
- Removed the mismatched flat/cartoon combat atlases, comic crypt arena, blurred legacy map backgrounds, brass/gothic clock art, and the separate rigged 3D prototype pipeline. Boss encounters no longer swap to a different playable character or rendering language.
- Replaced all fourteen active relic illustrations and the Hollow Coin with isolated transparent object renders. Relic cards now reserve roughly sixty percent of their composition for large, centered object art instead of using event-like scenery.
- Rebuilt the chronometer face and center sigil in the same crystalline material language while preserving the nine-hour game structure and overlaid socket information.
- Lowered and centered player and enemy HP/Block/status panels beneath their characters.
- Replacement choices now show the relic being placed. The first-battle offer uses option-specific scenery drawn from the approved screen-art family.
- Rebuilt **Inspect Battlefield** as an opaque tactical view centered on two enlarged clocks. It explains the player's full-cycle accumulated attack, Block, Strength, Thorns, statuses and hour sequence; the enemy side totals only revealed hours so hidden intents remain concealed.
- Map, collection, reward, summary, loading, shop, rest, win and loss presentation now use the approved cyan/amber crystalline screen family.

## Validation and limitations

Automated validation covers starter-relic mechanics, non-mutating outcome previews, hidden enemy intents, nine-hour assembly and three-sector combat flow, encounter playthroughs, 1080p/720p/ultrawide layouts, large text, contextual first-battle scenery, replacement artwork, and the expanded inspection view. Rendered 1080p review covers assembly, replacement, battlefield inspection and the pre-battle offer.

The combat rules, damage values, enemy AI, clock mechanics, relic effects, turn order, progression and run rules remain unchanged; no autoplay was added. Save data remains compatible, but starting a new run is recommended for visual review. Scripted encounter outcomes are unchanged from the existing balance fixtures and are not human boss-balance acceptance. The installer is unsigned, and interactive installer-wizard testing remains outstanding.

Intended source tag: **v0.25.0-test**, branch **feat/yonatan-tactical-inspection**. This is a prerelease for partner visual acceptance; gameplay remains on the feature branch pending review.
