# Overkill 0.13.0 — starter relic test build

Windows x64 playtest build. Start a **new run** for the new starter deck; existing saved inventories are preserved.

- 16 relics: six attacks (6 damage), six blocks (6 Block), two Twin Blades (4 damage twice), two Reinforced Walls (8 Block).
- Block remains until absorbed or the battle ends.
- Floating relic selection and replacement panels; pulsing clock destinations; full-height combat arena.

Install with OverkillSetup-0.13.0.exe, or extract every file from Overkill-0.13.0-Windows.zip into one folder and run Overkill.exe. Keep Overkill.pck beside the executable. No Godot installation is required.

This is a test release. The deterministic basic policy wins the first normal and elite fixtures, loses the first boss, and can stall in later boss fixtures without varied reward relics. Boss balance and full-run progression need playtesting.

The installer is not code-signed. Windows may show an unknown-publisher prompt.
