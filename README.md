# Overkill

## Download and test

**[Download the Windows installer — 0.30.0 playtest](https://github.com/UnKami/Overkill/releases/download/v0.30.0-test/OverkillSetup-0.30.0.exe)**

[Portable Windows ZIP](https://github.com/UnKami/Overkill/releases/download/v0.30.0-test/Overkill-0.30.0-Windows.zip) · [All releases](https://github.com/UnKami/Overkill/releases) · **[Update log](UPDATE_LOG.md)**

Install and start a **new run** to review the painterly-real cyan/amber world, cleaner battle composition, centered map icons, enlarged relic objects, slower combat reactions and relic upgrade transformation. Press **I** during battle to inspect both clocks and their numerical full-cycle forecasts; press **Esc** for the Combat Log and How to Play. Regular battles, elites and bosses share the same illustrated combatants; only the cinematic environment changes by encounter. This is an unsigned prerelease for player testing; human balance and visual acceptance remain open.

## Partner sync

Every delivered gameplay feature or update must have a versioned GitHub Release, downloadable Windows installer, and entry in the [update log](UPDATE_LOG.md). Release notes identify the exact source commit, test results, known issues, and save compatibility. Downloads live in Releases; the [installer folder](installer/README.md) provides direct links.

The 0.30.0 playtest is built from the exact source commit identified in [the update log](UPDATE_LOG.md), tagged `v0.30.0-test`, on `fix/yonatan-full-ui-polish`. Gameplay remains on its feature branch; the default-branch download links identify the test build separately from main's source state.
