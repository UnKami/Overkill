Install and start a **new run** to review the painterly-real cyan/amber direction, clearer battle staging, centered route icons, larger essence-colored relics, slower combat reactions and the relic Upgrade transformation. Press **I** during battle for two enlarged clocks and numerical full-cycle forecasts; press **Esc** for Combat Log and How to Play. Regular fights, elites and bosses share the same illustrated combatants against character-free scenery. This unsigned prerelease passed source/export suites and a silent install/launch check; human visual acceptance and full-run balance review remain open.
